# Интеграция интернет-магазина (ИМ) — blueprint

Каркас под будущий перенос движка магазина. **Код здесь не внедряется** — сначала
движок доводится до конца в chillafish/avenir, затем переносится сюда как есть.
Этот документ фиксирует, куда что ляжет, чтобы перенос был механическим.

Эталон движка: `~/Projects/chillafish/server/site` (localStorage-корзина + drawer +
checkout → `POST /api/orders`, серверный расчёт итога). Витрина avenir — на Medusa
(другой класс, для ZipString пока не нужен).

## Что уже готово и переиспользуется

| Актив | Путь | Роль в ИМ |
|-------|------|-----------|
| Каталог товаров | `data/products.csv` | источник карточек (Original/Luma/Aracna + нитки) |
| Дизайн-токены | `zipstring-ds/tokens.css` | стили витрины наследуют отсюда |
| Медиа-банк | `assets/img`, `assets/video` | фото/видео товаров |
| Ссылки маркетплейсов | `js/main.js` → `SHOP_LINKS` | текущая модель продаж (WB/Ozon) |

## Целевая структура (по образцу chillafish)

Появится при переносе движка — сейчас только зарезервировано:

```
pages/
  catalog/index.html      — сетка товаров (категории при необходимости)
  product/<slug>/index.html — карточка с кнопкой «В корзину» (data-art, data-price)
  checkout/index.html     — форма оформления
  success/index.html      — страница «заказ принят»
css/store.css             — стили витрины (drawer-корзина, каталог, checkout)
js/store.js               — движок: корзина в localStorage + drawer + submit заказа
```

Ключевые элементы движка chillafish, которые переносятся 1:1:
- `KEY = 'zipstring_cart'` — корзина в localStorage;
- drawer-разметка корзины в шапке (`#cart-open`, `#drawer`, `#cart-items`);
- `POST /api/orders` — **итог считает сервер**, цены на экране справочные;
- потолок количества (chillafish: 20 шт) и правила доставки.

## Развилка: как продаём

Сейчас модель — **отправка на маркетплейсы** (`SHOP_LINKS`, кнопки WB/Ozon).
Собственная корзина+checkout нужна, только если решим продавать напрямую с сайта
(нужен бэкенд `POST /api/orders` на Timeweb VPS — docker-стек в `/opt/zipstring/`).

Пока модель маркетплейсов не отменена — движок корзины **не подключаем**.

## Шаги переноса (когда движок будет готов)

1. Скопировать `store.js` + `store.css`, заменить `KEY` и брендовые тексты.
2. Сгенерировать `catalog/` и `product/*` из `data/products.csv`.
3. Вставить drawer-корзину в общий `<header>` всех страниц.
4. Поднять бэкенд заказов (`/opt/zipstring/`, свой Postgres) — по карте сервера.
5. Юр-страницы уже есть: `pages/privacy/`, `pages/terms/` (дополнить оферту под прямую продажу).

## Юр. и правовое (152-ФЗ)

- `pages/privacy/` — Политика конфиденциальности ✅ (черновик, нужна вычитка юриста)
- `pages/terms/` — Пользовательское соглашение ✅ (черновик)
- Реквизиты оператора (ИНН/ОГРН/адрес) — **заполнить перед публикацией**.
- При прямой продаже с сайта оферту дополнить условиями оплаты/доставки/возврата.
