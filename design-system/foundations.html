Токены системы

Основы

Все примитивы темы Neon Loop: цвет, типографика, ритм, форма, свет и движение. Значения — из tokens.css, источника истины. Не выдумывай новые — бери токен --zs-* и вставляй как есть.

Палитра

Цвет

Тёмный холст, один лаймовый акцент, служебные тона текста и маркетплейсов. Светлых фонов в теме нет.

Продуктовые тона

Каждый SKU ведёт свой цвет через --zs-tone. Тон задаётся атрибутом data-sku на секции или странице.

Originaldata-sku="original" · tone = лайм
Luma · UV-свечениеdata-sku="luma" · tone = #7C3AED
Aracna · вебшутерdata-sku="aracna" · tone = #CB11AB
База: --zs-tone UV: --zs-uv #7C3AED Web: --zs-web #CB11AB

Маркетплейсы

Wildberries--zs-wildberries · #CB11AB
Ozon--zs-ozon · #005BFF
<section data-sku="luma">
  <h2 style="color: var(--zs-tone)">Luma</h2>      /* → фиолетовый UV */
  <a style="box-shadow: var(--zs-glow-tone)">...</a>  /* halo под тон SKU */
</section>

Один акцент на экран. Не смешивай лайм и продуктовые тона в одном блоке — тон переопределяет акцент только внутри своего SKU-контекста.

Движение

Движение

Горизонтальное, «нить летит». Один easing, две скорости. Без пружин и bounce.

ТокенЗначениеГде
--zs-fast150mshover, наведение, мелкие чипы
--zs-normal300msпоявление, свечение, карточки
--zs-easecubic-bezier(0.16, 1, 0.3, 1)easing по умолчанию для всего
Наведи на меня → transform + glow на --zs-fast / --zs-normal 
.btn { transition: transform var(--zs-fast) var(--zs-ease),
                    box-shadow var(--zs-normal) var(--zs-ease); }
.btn:hover { transform: translateX(6px); box-shadow: var(--zs-glow); }
Раскладка

Контейнер

--zs-container = 1200px — максимальная ширина контентной колонки. Центрируется по горизонтали, дышит боковыми полями на узких экранах.

.wrap { max-width: var(--zs-container); margin-inline: auto;
        padding-inline: clamp(1rem, 4vw, 3rem); }

Полноширинные фоны и видео — на всю ширину вьюпорта; текст и сетки — внутри контейнера.
