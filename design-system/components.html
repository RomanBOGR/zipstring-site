UI-кит

Компоненты

Живые компоненты сайта ZipString: настоящие классы из css/main.css, живьём в тёмной сцене + копируемый HTML под каждым. Всё держится на токенах --zs-*. Меняешь бренд — правишь tokens.css, компоненты подхватывают.

Демо подтягивают реальный ../css/main.css — что видишь, то и в проде
Действия

Кнопки

Дисплейный шрифт, uppercase, лайм для главного действия. Маркетплейс-кнопки несут фирменный цвет площадки (WB — маджента, Ozon — синий) и ставятся только для товаров, которые реально в продаже.

.btn-primary · .btn-secondary

Основная пара CTA. Primary — лайм на чёрном, единственный на экране. Secondary — контурная, для второстепенного пути.

Купить набор Смотреть трюки 
<a href="#" class="btn-primary">Купить набор</a>
<a href="#" class="btn-secondary">Смотреть трюки</a>

Где: hero (.hero-actions), CTA-баннер (.cta-btns), spotlight (.spotlight-actions).

.btn-wb · .btn-ozon

Кнопки покупки на маркетплейсах. Компактные, фирменный цвет площадки. Ссылки централизованы в SHOP_LINKS.

Wildberries Ozon 
<div class="product-buy-btns">
  <a href="#" class="btn-wb">Wildberries</a>
  <a href="#" class="btn-ozon">Ozon</a>
</div>

Где: карточка товара (.product-buy-btns), блок покупки на странице продукта (.product-buy-row).

.btn-soon

Заглушка «Скоро в продаже» для SKU вне РФ-запуска (Luma). Пунктирная рамка в UV-фиолетовом, cursor: default — не ведёт никуда.

Скоро в продаже 
<span class="btn-soon">Скоро в продаже</span>

Где: карточка/страница Luma вместо кнопок WB/Ozon, пока товара нет в продаже.

Маленькие сигналы: статус в hero, «шапка» секции, токен-пилюли. Все лаймовые, дозированно.

Атмосфера

Свечение (glow)

Неоновое halo — визуальная подпись Neon Loop. Задаётся токенами тени, а не хардкодом. Тон свечения тянется из --zs-tone (лайм у Original, UV у Luma).

--zs-glow-soft
--zs-glow
--zs-glow-tone
(Luma / UV)
<!-- halo из токенов, без хардкода rgba -->
<div style="box-shadow: var(--zs-glow-soft)">...</div>
<div style="box-shadow: var(--zs-glow)">...</div>

<!-- тоновое свечение: цвет тянется из --zs-tone секции -->
<section data-sku="luma">
  <div style="box-shadow: var(--zs-glow-tone)">...</div>
</section>

Где: hover карточек, CTA-баннер (.cta-inner::before), spotlight-glow, hero-фон. Дозированно — 1–2 источника света на экран.

Правила применения

Do / Don't

Делаем

  • WB / Ozon-кнопки — только у товаров, реально в продаже
  • Для Luma (вне РФ-запуска) — .btn-soon «Скоро в продаже»
  • Один .btn-primary на экран — главный путь
  • Цвет свечения берём из --zs-tone секции/SKU
  • Свечение через токены --zs-glow*, не хардкод rgba
  • label for всегда связан с id поля

Не делаем

  • Не ставим WB / Ozon там, где товара ещё нет
  • Не заменяем .btn-soon активной кнопкой-заглушкой
  • Не кладём два .btn-primary рядом
  • Не пишем box-shadow: 0 0 24px #C6FF00 руками
  • Не убираем .hero::after — текст сольётся с видео
  • Не заливаем радугой акцентов один экран
