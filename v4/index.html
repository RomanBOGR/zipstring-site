Десять главных страниц, собранных по десяти разным установленным скиллам. У каждого взяты его собственные правила и пресеты — не общая «красота», а конкретная методика. Контент везде одинаковый, отличается подход.

Клей

Мягкий 3D: толстые границы, двойные тени, крупные пилюли. Стиль для детских продуктов.

Взято из скилла: стиль Claymorphism и пара шрифтов из его каталога — выданы командой --design-system. hallmark

Манифест

Страница-заявление: тезис, доказательство, выбор. Ничего лишнего.

Взято из скилла: макроструктура Manifesto, плавающая пилюля-навигация N5, футер-заявление Ft5, дисциплина OKLCH и запрет курсива в заголовках. modern-web-design

Горизонт

Лента трюков едет вбок, пока страница идёт вниз. Счётчики оживают в кадре.

Взято из скилла: паттерны Immersive Hero, Horizontal Scroll Gallery, Staggered Reveals, Animated Stats — без перехвата прокрутки. landing-page-design

Оффер

Продающая страница по канону: боль, решение, шаги, цены, вопросы.

Взято из скилла: формула первого экрана и порядок секций Hero → Social proof → Problem → Solution → How it works → Pricing → FAQ → Final CTA, липкая кнопка на мобильном. web-typography

Читальня

Разбор продукта текстом: мера 65 знаков, чистая иерархия, боковая карточка фактов.

Взято из скилла: диагностика типографики — тело 17–19px, интерлиньяж 1.6, контраст уровней размером и весом, подчёркнутые ссылки. microinteractions

Пульт

Кнопка запуска работает как настоящая: покой, разгон, полёт. Длина нити меняет петлю.

Взято из скилла: схема Саффера «триггер → правила → обратная связь → циклы», отклик до 100 мс, подсказка гаснет после двух запусков. refactoring-ui

Система

Сдержанный продуктовый интерфейс: шкалы, тонированные серые, лестница теней.

Взято из скилла: сначала оттенки серого — цвет последним, шкала 4/8/16/24/32/48/64, иерархия одним-двумя рычагами, тёмный не чёрный, а #111827. huashu-design

Дек

Не страница, а презентация 16:9: стрелки, счётчик, обзорная стена по Esc.

Взято из скилла: «делаешь слайды — не делай веб-страницу»: фиксированный кадр с автомасштабом, обзор всех слайдов, только настоящие ассеты. design-everyday-things

Понятно

Каждый блок отвечает на вопрос: что сделать, что произойдёт, что если не подойдёт.

Взято из скилла: два разрыва Нормана — исполнения и оценки; кнопки с пояснением, что случится после нажатия; путь восстановления после ошибки. motion-layer

Слой движения

Появления, маска по словам, честный прогресс чтения, отклик в точке касания.

Взято из скилла: начальные состояния только под .js, ровно четыре длительности, счётчики с резервированием ширины, reduced-motion гасит движение, но не интерактив.
Скиллы взяты из установленного набора (каталог — bogr.ai/skills). Палитра и шрифты везде брендовые; там, где скилл предлагал свои (например Baloo 2 в Claymorphism), это указано в карточке.
