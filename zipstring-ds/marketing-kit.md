# ZipString — маркетинг-кит (креативы, реклама, контент)

Рабочий арсенал для рекламы и контента. Источники (Google Drive, BabyOptGroup):
сравнительный анализ конкурентов, обзор рынка (MPStats), контент-план, SMM-стратегия.
Голос и стоп-слова — строго по [ai-kit.md](ai-kit.md). Смыслы — [brand.json](brand.json).

## Рыночный контекст

- Категория новая и почти без сильных игроков в РФ. Народные названия (= **SEO/ключи
  для карточек и рекламы**): **веревкомет · зип стринг · Loop Lasso / Луп лассо ·
  СтрингШутер · антийойо · веревочная пусковая установка · антистресс-игрушка с нитью**.
- Конкуренты дешёвые (≈220–900 ₽), ZipString — **премиум ≈2000 ₽**. Значит цену
  оправдываем качеством, надёжностью и библиотекой трюков, а не «дешевле всех».
- Позиция: не «ещё один веревкомет с WB», а **оригинал, который не ломается и умеет 100+ трюков**.

## Слабости конкурентов → наши рекламные аргументы

Из отзывов и тестов конкурентов (RomaLab, ЦДМ, ЗАНДЕР, Semybear):

| Боль у дешёвых аналогов | Наш аргумент (для креатива) |
|---|---|
| Нити путаются и рвутся | Нить не путается и не рвётся — 3 сменные в комплекте |
| «Крутится только по кругу» | Не только круг — **100+ трюков** по библиотеке |
| Работают от батареек (нет в комплекте, обман) | **USB-C аккумулятор** — заряжается, батарейки не нужны |
| Кнопка/мотор быстро ломаются | **2 синхромотора** — стабильное вращение, надёжная механика |
| Нет инструкции | Инструкция + библиотека трюков и видео по QR |
| Шумит | Работает ровно, без грохота |

> Приём: «дёшево — но ломается за неделю» против «дороже — и радует надолго».

## Боли покупателя (из бренд-платформы)

1. Ребёнка не вытащить из дома / из телефона.
2. В поездке/на даче нечем занять, кроме гаджета.
3. Игрушки надоедают за день.
4. Новый непонятный продукт — страшно, что сложно/на один раз.

Каждый креатив закрывает одну боль + показывает продукт в действии.

## Рекламные углы (hooks)

- «Эта штука наконец оставит вас в покое» — мама отдыхает, дети играют вдвоём.
- «Первый трюк — за 10 минут» / «Справится даже ребёнок».
- «Не игрушка на один день — 100+ трюков и челленджи».
- «В школу, во двор, на дачу — влезает в карман».
- «Дешёвые веревкометы рвутся и путаются. Это — оригинал».
- «В основе — законы физики. На выходе — магия». → финал: **«Запускай. Удивляй.»**

## Рубрики контента (reels — основной формат)

1. **Сценарии одному** — трюки, эксперименты, «занять себя без экрана».
2. **С другом/семьёй** — повод собраться, играть вдвоём.
3. **Повтори трюк с первого раза** — доступность, «получится у каждого».
4. **Челлендж** — «кто быстрее», «повтори», по раундам.
5. **Сценарии в разных местах** — двор, дача, дорога, школа (окупаемость).

## Готовые идеи роликов (из контент-плана)

- «Эта штука оставит вас в покое»: мама спит/отдыхает на фоне, дети играют вдвоём.
- «Три трюка, которые можно сделать с ZipString» — быстрый набор.
- «Повтори трюк с первого раза»: люди, которые ещё не пробовали ZipString.
- **Aracna в быту**: закрыть дверь, притянуть предмет «как Человек-паук».
- Челлендж с шоколадом по раундам · трюки с дедулей · «entertained 45 минут подряд».
- Инструкции Original / Aracna · «Где купить» (WB/Ozon) · Stories-розыгрыши.

## Идеи розыгрышей (Zipster)

- «Придумай свой трюк» — самым креативным Aracna.
- «Мой первый трюк с ZipString» — 3 победителя получают Original/Aracna.
- «Сними трюк N с хештегом» · «отметь друга для баттла» (VK).

## Aracna — акцент запуска

Крючок: **запуск И возврат нити одним нажатием** — «как Человек-паук, по-настоящему».
