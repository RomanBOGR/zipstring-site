# ZipString Design System — AI Kit v2.0 (тема Neon Loop)

> Правила и токены бренда ZipString для AI-ассистента.
> Источник смыслов — `brand.json` (выверен по бренд-платформе BabyOptGroup 18.05.2026),
> реклама/креативы/контент — `marketing-kit.md`, ассеты — `docs/assets-map.md`.
> Подключение: `<link rel="stylesheet" href="zipstring-ds/tokens.css">`

## Бренд в одном абзаце

ZipString — американская трюковая игрушка с летающей нитью. Петля из нити вращается
(двухроликовая система запуска) и позволяет выполнять зрелищные трюки. Переключает
детей и подростков с телефона на живую игру, движение и общение; удобно брать с собой
куда угодно. Слоган **«Дай волю восхищению»**, подпись-формула **«Запускай. Удивляй.»**
В РФ — официальный дистрибьютор (ООО «Бэйби Опт Груп»), продажи на Wildberries и Ozon.

## Тема Neon Loop — что это значит

| Делаем | Не делаем |
|---|---|
| Тёмный холст `#080808`, свет от неона и продукта | Светлые/белые фоны «для чистоты» |
| Один акцент — лайм `#C6FF00`, дозированно | Радуга акцентов на одном экране |
| Каждый SKU ведёт свой тон (`--zs-tone`) | Мешать тона Original/Luma/Aracna без причины |
| Движение горизонтальное — «нить летит вперёд» | Пружинящие bounce-анимации |
| Unbounded крупно для вау, Onest для чтения | Три шрифта на экране |
| Видео-демо трюков крупным планом | Стоковые градиентные блобы |

Причина тёмной темы: трюки контрастнее на тёмном, неоновая нить — визуальный код
бренда. **Здесь тёмная тема — правильная** (в отличие от многих детских брендов).

## Цвет

**Не выдумывать цвета.** Все — в `tokens.css` / `brand.json`.

| Токен | HEX | Где |
|---|---|---|
| `--zs-bg` | `#080808` | Основной фон |
| `--zs-lime` | `#C6FF00` | Акцент бренда, CTA, hover |
| `--zs-tone` | = SKU | Продуктовый тон секции |
| `--zs-uv` | `#7c3aed` | Luma (свечение) |
| `--zs-web` | `#CB11AB` | Aracna |
| `--zs-wildberries` | `#CB11AB` | Кнопка WB |
| `--zs-ozon` | `#005BFF` | Кнопка Ozon |

Продуктовый тон переключается контейнером: `data-sku="luma"` → `--zs-tone` станет
UV-фиолетовым автоматически.

## Типографика

- **Unbounded** (400/700/900) — дисплей, заголовки, hero.
- **Onest** (300/400/500/600) — текст, UI. Обе с кириллицей (Google Fonts).
- База `--zs-text-base` (~17px, clamp), интерлиньяж 1.6, hero `--zs-text-hero`.

## Форма и движение

- Радиусы 12 / 20px (`--zs-radius` / `--zs-radius-lg`).
- Переходы `--zs-ease` (expo-out), `--zs-fast`/`--zs-normal`.
- Анимируем только `transform` / `opacity` (compositor-friendly).

# ГОЛОС БРЕНДА (обязательно для любого копирайта)

**Принцип:** сначала показать продукт в действии, затем объяснить ценность и только
потом — характеристики. Бренд **не объясняет, а показывает. Не убеждает, а удивляет.**

## Тональность

Энергичная (не хаотичная) · Простая (не поверхностная) · Трендовая (не ультрамодная) ·
Современная (не безликая) · Дружелюбная (не свойская) · Честная (не заискивающая).
Короткие предложения, глаголы в повелительном наклонении, «!» там, где уместно.

## Обращение по сегментам

| Кому | Как |
|---|---|
| Дети 7–12 | На «ты»: «попробуй», «освой», «покажи». Живо, коротко, с вызовом. |
| Подростки 12–14 | На «ты» как к равному. Акцент на соцсети, трюки, соревнование. |
| Родители | На «вы», уважительно и по делу. Без давления. Акцент на пользе и простоте. |
| Блогеры | На «ты» как к партнёру. «Момент восхищения», вирусность, простота демо. |
| Общие тексты | Безличные конструкции или «вы» (смешанная аудитория). |

## ✅ Лексика бренда

- **Действия:** запускать, осваивать, придумывать, делиться, парить, летать, крутить, показывать, изобретать, соревноваться, удивлять, переключаться, оторваться.
- **Эмоции:** удивление, восторг, «момент восхищения», магия, азарт, зрелищный, живой, эффектный.
- **Физика (с пояснением):** законы физики, баланс, движение, нить, петля, запуск, натяжение, инерция.
- **Сценарии:** двор, улица, дача, школа, дорога, отпуск, компания, перемена, лагерь, площадка, вечеринка.
- **Сообщество:** зипстер, клуб, трюки, челленджи, контент, фанаты, вирусный.

## ⛔ Стоп-слова (НЕ использовать)

- **Пустые усилители:** лучший в мире, невероятный, **уникальный**, **революционный**, **не имеющий аналогов**, абсолютно, идеально, на 100%, безусловно, фантастически.
- **Инфантильное:** игрушечка, малыш, крошка, карапуз, зайчик, деточка.
- **Канцелярит:** осуществлять, реализовывать, представлять собой, в случае необходимости, в целях.
- **Заискивание:** специально для вас, только для лучших родителей, ваш ребёнок заслуживает лучшего.
- **Техтермины без пояснения** (кроме упаковки/B2B): двухроликовая система, электромеханический привод, траектория петли.

## Речевые формулы (структуру сохранять, не дословно)

- `[Что это] + [как работает] + [что получаешь]` → «ZipString — трюковая игрушка с летающей нитью. Нажми на кнопку — и нить парит в воздухе. Осваивай трюки с первых минут.»
- `[Сценарий] + [продукт]` → «На даче, во дворе, в дороге — ZipString всегда с тобой.»
- `[Польза ребёнку] + [спокойствие родителя]` → «Ребёнок увлечён без телефона и без уговоров.»
- `[Факт] + [вывод]` → «Более 2 миллионов покупателей по всему миру.»
- `[Физика] + [магия]` → «В основе — законы физики. На выходе — магия.»
- `[Глагол]. [Глагол].` (финал/упаковка) → «Запускай. Удивляй.»

## Названия трюков (RU, канон)

Штопор · Проскок · Портал · Бесконечность · Стрельба из лука · Человек-паук · Лассо · Непослушная нить.

## Что нельзя делать бренду

1. Говорить сложным языком о технологиях — усложнение усиливает непонимание новой категории.
2. Фокусироваться на одном возрасте — продукт 4+, интересен разным сегментам.
3. Игнорировать демонстрацию — без видео новый продукт трудно понять.
