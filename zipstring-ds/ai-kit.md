# ZipString Design System — AI Kit v1.0 (тема Neon Loop)

> Правила и токены бренда ZipString для AI-ассистента.
> Источник смыслов — `docs/brand-brief.md`, ассеты — `docs/assets-map.md`.
> Подключение: `<link rel="stylesheet" href="zipstring-ds/tokens.css">`

## Бренд в одном абзаце

ZipString — устройство, запускающее бесконечную петлю нити в воздух (два
синхромотора + центробежная сила). Виральная STEM-игрушка из TikTok и Kickstarter,
100+ трюков, для всей семьи 4–99. Слоган **«Дай волю восхищению»**. В РФ —
официальный дистрибьютор против подделок, продажи на Wildberries и Ozon.

## Тема Neon Loop — что это значит

| Делаем | Не делаем |
|---|---|
| Тёмный холст `#080808`, свет от неона и продукта | Светлые/белые фоны «для чистоты» |
| Один акцент — лайм `#C6FF00`, дозированно | Радуга акцентов на одном экране |
| Каждый SKU ведёт свой тон (`--zs-tone`) | Мешать тона Original/Luma/Aracna без причины |
| Движение горизонтальное — «нить летит вперёд» | Пружинящие bounce-анимации |
| Unbounded крупно для вау, Onest для чтения | Три шрифта на экране |
| Видео-демо трюков крупным планом | Стоковые градиентные блобы |

Причина тёмной темы: продукт светится (Luma), трюки контрастнее на тёмном,
неоновая нить — визуальный код бренда. **Здесь тёмная тема — правильная** (в
отличие от многих детских брендов).

## Цвет

**Не выдумывать цвета.** Все — в `tokens.css` / `brand.json`.

| Токен | HEX | Где |
|---|---|---|
| `--zs-bg` | `#080808` | Основной фон |
| `--zs-lime` | `#C6FF00` | Акцент бренда, CTA, hover |
| `--zs-tone` | = SKU | Продуктовый тон секции |
| `--zs-uv` | `#7c3aed` | Luma (свечение) |
| `--zs-web` | `#CB11AB` | Aracna (вебшутер) |
| `--zs-wildberries` | `#CB11AB` | Кнопка WB |
| `--zs-ozon` | `#005BFF` | Кнопка Ozon |

Продуктовый тон переключается контейнером: `data-sku="luma"` → `--zs-tone` станет
UV-фиолетовым автоматически.

## Типографика

- **Unbounded** (400/700/900) — дисплей, заголовки, hero. Геометричный гротеск,
  под «поп/вирал».
- **Onest** (300/400/500/600) — текст, UI. Обе с кириллицей (Google Fonts).
- База `--zs-text-base` (~17px, clamp), интерлиньяж 1.6, hero `--zs-text-hero`.

## Форма и движение

- Радиусы 12 / 20px (`--zs-radius` / `--zs-radius-lg`) — мягкие, дружелюбные.
- Переходы `--zs-ease` (expo-out), `--zs-fast`/`--zs-normal`.
- Анимируем только `transform` / `opacity` (compositor-friendly).

## Тон текста

Восхищение и вопрос («Как это работает? Это магия?»), семейно, энергично, коротко,
без пафоса. Родитель — партнёр, не объект продажи. На «ты» с аудиторией уместно.

## Ассеты

Медиа-банк — `assets/zipstring-media/` (2.3 ГБ, не в git). Доступ через
`named/` (симлинки с именами) и `slug_map.tsv`. Подробно — `docs/assets-map.md`.
168 видео (101 трюк!), 545 фото, пресс-логотипы для соцдоказательства.
